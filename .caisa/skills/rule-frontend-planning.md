# Description
- Use this skill only when the frontend does not yet have an established implementation. - This is a planning skill. Do not build final pages, layouts, reusable components, feature components, stores, services, routing, or backend functionality. - Do not select or execute implementation skills. The Frontend Orchestrator owns implementation coordination. - Plan what must be built. Do not decide which downstream skill will build it. - Do not invent requirements, components, pages, modules, endpoints, stores, services, files, or architecture that are not supported by authoritative project sources. - Preserve source ownership. Reference authoritative sources instead of redefining them unnecessarily. - Report missing information, missing references, ambiguous ownership, or conflicting requirements as blockers.
