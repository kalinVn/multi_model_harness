# Name
build-component

# Description
Build a project component that follows the existing architecture and conventions.

# Instructions
Inspect the surrounding components and project conventions before making changes.
Define the component responsibility, inputs, outputs, and dependencies clearly.
Reuse existing domain models, services, and patterns instead of creating duplicate abstractions.
Implement only the requested component and avoid unrelated refactoring.
Use only the tools allowed by the active agent.
Verify the component in proportion to the requested change and report the result.
